# API Security Reports

A practical, defensive collection of API security research for developers, architects, and security teams. Examples should be tested only in systems you own or are authorized to assess.

## Reports

1. **API Security Threat Landscape** — Why APIs are now a primary application attack surface.
2. **OWASP API Security Top 10** — A plain-language guide to the current risk categories and mitigations.
3. **Broken Object-Level Authorization** — How teams design authorization checks around object ownership.
4. **OAuth, OIDC, and JWT Security** — Token lifecycle, audience validation, rotation, and revocation.
5. **GraphQL Security Risks** — Introspection, query depth, authorization, and resource controls.
6. **Shadow and Zombie APIs** — Inventory, ownership, lifecycle management, and retirement.
7. **API Rate-Limit Abuse** — Quotas, burst control, account-level limits, and abuse detection.
8. **SSRF Through API Integrations** — Safe URL-fetch design, egress controls, and metadata protection.
9. **Sensitive Data Exposure in APIs** — Response minimization, filtering, logging, and privacy review.
10. **API Security Testing Checklist** — A repeatable pre-release and production review workflow.
